# Employee-Salary-Prediction
Sviluppo di un progetto Python per la previsione degli stipendi annuali mediante regressione lineare (Scikit-learn) e rete neurale feedforward (PyTorch).  Analisi esplorativa del dataset, preprocessing delle variabili e suddivisione dei dati in training e test.  Addestramento e valutazione comparativa dei modelli mediante metriche
